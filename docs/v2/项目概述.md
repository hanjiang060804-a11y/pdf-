# 墨流 2.0 项目概述

> **版本**：2.0.0-plan  
> **最后更新**：2026-06-23

## 1. 产品定位

在微信里完成 PDF 译中：从聊天或本地选 PDF → 云端翻译 → 下载或转发译文。

**一句话**：1.x 是「本机工具」；2.0 是「微信里的翻译服务」。

## 2. 目标用户

- 手机收到论文/资料 PDF，不想拷到电脑
- 已在用墨流 1.x，希望移动端同样体验
- 可接受「文件上传云端处理」（需明确告知）

## 3. MVP 范围（M1）

- [ ] 微信小程序：选 PDF → 检测 → 翻译 → 下载 mono
- [ ] 云端 FastAPI（复用 `pdf_tra.service`）
- [ ] HTTPS 域名 + 微信合法域名配置
- [ ] 文字版 PDF；英文→简体中文
- [ ] 简单防滥用（单 IP / openid 日限额）

## 4. 非目标（M1 不做）

- 小程序内本地跑 pdf2zh（不可行）
- 用户自带 DeepSeek Key（体验差，二期可考虑高级用户）
- 扫描版 OCR（M2/M3，服务器需装 OCR 栈）
- 替换或下线 1.x Web/CLI

## 5. 里程碑

| 阶段 | 内容 | 产出 |
|------|------|------|
| **M1** | 云 API + 极简小程序 | 内测版 |
| **M2** | 微信登录、COS、配额、完成通知 | 小范围公测 |
| **M3** | OCR、对照版、历史记录 | 上架准备 |
| **M4** | 审核、计费（可选） | 正式版 2.0.0 |

## 6. 技术要点

- 前端：`wx.chooseMessageFile` + `wx.uploadFile` + 轮询 `/api/v1/jobs/{id}`
- 后端：在 1.x `pdf_tra/web/server.py` 上增加微信鉴权、对象存储
- 部署：腾讯云 CVM 或容器 + 备案域名

## 7. 风险

| 风险 | 应对 |
|------|------|
| 翻译耗时长 | 异步任务 + 订阅消息 |
| API 费用 | 配额、页数上限 |
| 隐私合规 | 用户协议、定期清理上传文件 |
| 微信审核 | 工具类目、无违规内容 |
