# 墨流 2.0 技术方案

> **版本**：2.0.0-plan  
> **分支**：`v2/wechat-miniprogram`  
> **依赖**：复用 `pdf_tra.service` + 1.x 流水线

---

## 1. 架构

```
┌─────────────────────────────────────────────────────────┐
│  微信小程序 (miniprogram/)                               │
│  wx.login · chooseMessageFile · uploadFile · download   │
└───────────────────────────┬─────────────────────────────┘
                            │ HTTPS + Bearer token
                            ▼
┌─────────────────────────────────────────────────────────┐
│  云 API (pdf_tra/web/ 扩展 或 pdf_tra/cloud/)            │
│  微信鉴权 · 配额 · 文件元数据 · 复用 JobStore            │
└───────────────────────────┬─────────────────────────────┘
                            │
          ┌─────────────────┼─────────────────┐
          ▼                 ▼                 ▼
    pdf_tra.service    对象存储 COS      Redis/DB（可选）
    inspect/translate  上传/译文临时URL   openid·任务·配额
```

**原则**：翻译逻辑零复制，只在 API 层加「云环境」横切能力（鉴权、存储、清理）。

---

## 2. 与 1.x API 的差异

| 端点 | 1.x Web | 2.0 云 |
|------|---------|--------|
| `POST /api/v1/inspect` | multipart 上传 | **保留**，需登录态 |
| `POST /api/v1/inspect/path` | 本地绝对路径 | **移除或内网-only** |
| `POST /api/v1/translate` | `{path}` 服务器路径 | 改为 `{file_id}` 或保留 path 但 path 为上传目录内 ID |
| `GET /api/v1/jobs/{id}` | 无鉴权 | **校验 job 归属 openid** |
| `GET /api/v1/jobs/{id}/download/*` | 直链 | 可改为 **COS 签名 URL** |
| `GET/PUT /api/v1/settings` | 用户填 API Key | **M1 移除**；Key 仅服务端 config |
| `GET /api/v1/capabilities` | 保留 | 保留（OCR 是否可用） |

### 2.1 建议新增端点（M1）

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/v2/auth/wechat` | `{code}` → `{token, openid}` |
| GET | `/api/v2/me` | 配额、今日已用页数 |
| POST | `/api/v2/translate` | `{file_id, ocr?}` 创建任务（不暴露服务器 path） |

M1 可暂用 v1 路径 + Header `Authorization: Bearer <token>`，减少改动面。

## 3. 鉴权

```text
小程序 wx.login() → code
     → POST /api/v2/auth/wechat { code }
     → 服务端 appid+secret 换 openid/session_key
     → 签发 JWT（openid, exp 7d）
后续请求 Header: Authorization: Bearer <jwt>
```

| 项 | 说明 |
|----|------|
| 密钥 | `WECHAT_APP_ID`、`WECHAT_APP_SECRET`、`JWT_SECRET` 环境变量 |
| Job 隔离 | `Job` 增加 `owner_openid`；查询/下载校验 |
| 匿名 | M1 不允许 |

---

## 4. 文件与存储

| 阶段 | 方案 |
|------|------|
| M1 内测 | 服务器磁盘 `uploads/{openid}/{uuid}.pdf`，定时清理 24h |
| M2 | 腾讯云 COS：上传直传或经 API 中转 |
| 译文 | 同上；下载走 `wx.downloadFile` 合法域名 |

上传限制（建议）：

- 单文件 ≤ 20MB（微信 `uploadFile` 默认上限 100MB，可按成本收紧）
- 页数 ≤ 100（M1）；超限返回 400 + 文案

---

## 5. 云服务器要求

| 组件 | 版本/说明 |
|------|-----------|
| OS | Ubuntu 22.04 LTS |
| Python | 3.10–3.12 |
| Poppler | pdfinfo / pdftotext |
| pdf2zh | 与 1.x 相同 venv |
| 进程管理 | systemd 或 Docker |
| 反向代理 | Nginx + TLS（Let's Encrypt 或云证书） |
| 域名 | 备案；配置微信「request / uploadFile / downloadFile 合法域名」 |

OCR（M3）：服务器安装 ocrmypdf、Tesseract、Ghostscript，与 1.x 安装指南一致。

## 6. 部署目录规划

```
deploy/
├── Dockerfile              # pdf_tra + poppler + pdf2zh
├── docker-compose.yml      # api + nginx（可选 redis）
├── nginx.conf
├── .env.example            # 微信、JWT、DeepSeek、COS
└── README.md               # 上线步骤
```

入口：`uvicorn pdf_tra.web.server:create_app --factory` 或独立 `pdf_tra.cloud.app`。

---

## 7. 安全与合规

- DeepSeek API Key **仅服务端** `config.json` / 环境变量
- 上传 PDF **24–72h 自动删除**
- 用户协议：说明文件上传云端、仅用于翻译
- 日志：不打印 PDF 内容；API Key 脱敏
- 限流：按 openid 每日页数 / 任务数

## 9. 验收标准（M1）

- [ ] 小程序从聊天选 PDF 并完成翻译下载
- [ ] 未登录请求返回 401
- [ ] 用户 A 不能访问用户 B 的 job_id
- [ ] 50 页以内英文 PDF 端到端 < 15min（视 API 速度）
- [ ] 合法域名、HTTPS 通过微信开发者工具校验
