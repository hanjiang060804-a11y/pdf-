# 墨流 2.0 小程序设计

> **版本**：2.0.0-plan  
> **视觉**：延续 1.x 水墨风（墨色 #1a1a1a、纸白、宋体标题）

---

## 1. 页面结构

```
miniprogram/
├── app.js / app.json / app.wxss
├── project.config.json
├── utils/
│   ├── api.js          # request 封装 + token
│   └── auth.js         # wx.login 换 token
├── pages/
│   ├── index/          # 首页：选文件 + 品牌
│   ├── inspect/        # 检测摘要（可合并到 index）
│   ├── progress/       # 翻译进度
│   └── result/         # 下载 / 预览 / 分享
└── components/
    ├── file-chip/      # 已选文件卡片
    ├── stat-grid/      # 页数/类型/语言
    └── progress-bar/
```

**M1 可简化为 2 页**：`index`（选+检测+开始）、`progress`（进度+结果下载）。

## 2. 用户流程

```text
打开小程序
  → 静默 wx.login + 换 token
  → 首页
       ├─ 「从聊天选择」→ wx.chooseMessageFile
       ├─ 「从手机选择」→ wx.chooseMessageFile（type=file）
       └─ 上传 wx.uploadFile → POST /api/v1/inspect
  → 展示：页数、文字版/扫描版、能否翻译
  → 「开始翻译」→ POST /api/v1/translate
  → 进度页：轮询 GET /api/v1/jobs/{id}（1s）
  → 完成：wx.downloadFile 译文 PDF
       └─ wx.openDocument 预览
       └─ 转发给好友 / 保存
```

扫描版 M1：**若 `needs_ocr && !ocr_available`** → 提示「暂不支持扫描版，请用电脑版墨流」；M3 再开 OCR。

## 3. 关键 API 调用

### 3.1 登录

```javascript
// utils/auth.js
export async function ensureLogin() {
  const { code } = await wx.login();
  const { token } = await api.post('/api/v2/auth/wechat', { code });
  wx.setStorageSync('token', token);
}
```

### 3.2 选文件并检测

```javascript
wx.chooseMessageFile({
  count: 1,
  type: 'file',
  extension: ['pdf'],
  success({ tempFiles }) {
    const file = tempFiles[0];
    wx.uploadFile({
      url: `${API_BASE}/api/v1/inspect`,
      filePath: file.path,
      name: 'file',
      header: { Authorization: `Bearer ${token}` },
      success(res) { /* 解析 JSON → 展示摘要 */ }
    });
  }
});
```

### 3.3 翻译与轮询

与 1.x `app.js` 逻辑对齐：`engine` / `polish` M1 用服务端默认，不提供设置页。

## 6. 与 1.x Web 对照

| 1.x Web | 2.0 小程序 |
|---------|------------|
| 拖拽上传 | 无；改为聊天/本地选文件 |
| 设置 API Key | 无；平台托管 |
| 下载按钮 | `downloadFile` + `openDocument` |
| toast | `wx.showToast` |
| 侧栏流程说明 | 首页简短三步图示 |

---

## 7. 非功能需求

- 首屏 < 2s（不含上传）
- 弱网：上传失败可重试；轮询失败指数退避
- 分包：M1 主包即可；水墨资源放 CDN 或本地（控制 2MB）
