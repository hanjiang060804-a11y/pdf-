# 安装指南

> **最后更新**：2026-06-23

## 1. 环境要求

| 项 | 要求 |
|----|------|
| **Python** | **3.10 ~ 3.12**（不支持 3.13 / 3.14） |
| **pdf2zh** | >= 1.9.11（经 pip 安装） |
| **poppler** | 系统安装 `pdfinfo`、`pdftotext` 并加入 PATH |
| **DeepSeek API Key** | config.json 或环境变量 |

---

## 2. 一键安装（Windows 推荐）

### 2.1 安装 Python 3.12

若只有 Python 3.14，需额外安装 3.12。

**国内镜像（推荐，纯命令行）：**

```powershell
# 华为云镜像下载 + 静默安装
curl -L -o $env:TEMP\python-3.12.10-amd64.exe `
  https://mirrors.huaweicloud.com/python/3.12.10/python-3.12.10-amd64.exe
Start-Process -FilePath $env:TEMP\python-3.12.10-amd64.exe -ArgumentList `
  "/quiet","InstallAllUsers=0","PrependPath=1","Include_test=0" -Wait
```

或官网：https://www.python.org/downloads/release/python-3129/（安装时勾选 **Add python.exe to PATH**）

验证：

```powershell
py -0p
# 应看到 -V:3.12 一行
```

### 2.2 运行项目脚本

```powershell
cd C:\Users\21763\Documents\pdf-tra

# 若 PowerShell 禁止脚本，先执行：
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

.\scripts\setup.ps1
```

脚本会自动：

1. 选用 Python 3.12 / 3.11 / 3.10
2. 创建 `.venv` 虚拟环境
3. 安装 `requirements.txt`
4. 复制 `config.example.json` → `config.json`

### 2.3 激活虚拟环境（以后每次使用）

```powershell
cd C:\Users\21763\Documents\pdf-tra
.\.venv\Scripts\Activate.ps1
```

## 3. 网络问题：PyPI SSL 失败

### 方案 A：开梯子（VPN）

开全局或规则代理后，在 **已激活的 .venv** 中：

```powershell
pip install -r requirements.txt
```

### 方案 B：国内镜像（不开梯子）

```powershell
.\scripts\setup-mirror.ps1
```

或手动：

```powershell
pip install -r requirements.txt `
  -i https://pypi.tuna.tsinghua.edu.cn/simple `
  --trusted-host pypi.tuna.tsinghua.edu.cn
```

## 4. 常见错误

| 报错 | 原因 | 解决 |
|------|------|------|
| `SSLEOFError` + `pypi.org` | 访问官方 PyPI 失败 | 开梯子 **或** 用镜像脚本 |
| `from versions: none` | 网络失败 **或** Python 版本不对 | 见上 + 确认 Python 3.12 |
| `Requires-Python >=3.10,<3.13` | 使用了 Python 3.14 | 安装 3.12，用 `setup.ps1` |
| `缺少外部工具: pdfinfo` | 未装 poppler | 见 §5 |

## 5. 安装 poppler（Windows）

### 方案 A：国内镜像脚本（推荐）

```powershell
.\scripts\install-poppler-mirror.ps1
```

自动从 GitHub 加速镜像下载、解压到 `%LOCALAPPDATA%\poppler`，并加入用户 PATH。

### 方案 B：winget（GitHub 直连，国内可能很慢）

```powershell
winget install oschwartz10612.Poppler
```

### 方案 C：手动

1. 下载：https://github.com/oschwartz10612/poppler-windows/releases  
2. 解压，将 `Library\bin` 目录加入系统 **PATH**  
3. 验证：`pdfinfo -v`

## 6. 验证安装

```powershell

python -m pdf_tra version
pdf2zh --help
```

```powershell
python -m pdf_tra inspect your.pdf
```

## 7. OCR（扫描版 PDF，Phase 3）

扫描版 PDF 需额外安装：

```powershell
# Tesseract（中文扫描需 chi_sim 语言包）
winget install UB-Mannheim.TesseractOCR

# Ghostscript（ocrmypdf 必需，Windows）
.\scripts\install-ghostscript.ps1

# ocrmypdf（在 .venv 内）
pip install ocrmypdf
```

验收：

```powershell
tesseract --list-langs
gswin64c --version
ocrmypdf --version
```

Web 端检测到扫描 PDF 且 OCR 可用时，按钮变为「OCR 识别并翻译」。

## 8. 手动安装（不用脚本）

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -U pip
pip install -r requirements.txt
copy config.example.json config.json
```
